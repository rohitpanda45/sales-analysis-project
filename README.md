## Project Overview

This project analyses retail sales data using Python to identify:
- Sales trends
- Top and bottom performing products
- Category-wise sales performance
- Regional sales performance
- Seasonal patterns
- Business insights and recommendations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

The project uses a demo retail sales dataset created for the internship project.
